# Market Monitor

Python automation for market monitoring and notifications.

The repository contains independent scanners, tracking code, and GitHub Actions workflows.

## Files

| File | Purpose |
|---|---|
| `monitoring_scanner.py` | Monitoring component |
| `market_scanner.py` | Market scanner |
| `tracker.py` | Signal tracking |
| `distribution_scanner.py` | Distribution checks |
| `.github/workflows/pipeline.yml` | Existing workflow |
| `.github/workflows/market_scanner.yml` | Market scanner workflow |
